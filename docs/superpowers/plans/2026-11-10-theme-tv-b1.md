# Thème TV « B1 » (menu SNES Mini + RetroArch + musique) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un hmod `snes_usa_b1` installable/désinstallable depuis hakchi qui habille le menu `clover-ui` de la SNES Mini EUR et le menu RetroArch 1.8.4 dans le langage B1, avec une musique de menu originale.

**Architecture:** Tout le thème est **généré par des scripts Python versionnés** dans `theme/` (aucun asset dessiné à la main, donc reproductible et relisible) : un codec pour les polices `.font` de Nintendo (BMFont binaire + en-tête), un repeintre de l'atlas `packed.png` qui garde exactement les cadres du `packed.json`, un synthétiseur numpy pour la musique, et un empaqueteur de hmod. Le hmod ne remplace des fichiers que par `mount_bind` au démarrage (même mécanisme que `font_remount`), donc la désinstallation rend la console d'origine.

**Tech Stack:** Python 3.12 (Pillow, numpy, pytest), fonte Jost (SIL OFL 1.1, géométrique façon Futura), busybox sh pour les scripts du hmod.

**Spec:** `docs/superpowers/specs/2026-11-10-hakchi-snes-usa-refonte-design.md` (§5, §5 bis, §8, §8 bis)

## Global Constraints

- Branche `snes-usa/theme-b1`, créée depuis `snes-usa/pochettes`. Push uniquement vers `origin` et sur demande ; jamais vers `upstream`.
- Palette B1, exactement : ardoise `#1C1B22`, filet `#2C2A34`, violet manette `#4A3C8C` (stries `#6B5BB5` / `#5747A0`), lavande `#A79FD6`, texte `#E4E2EA`, texte secondaire `#8E8A9C`. Aucun dégradé, halo, lueur, glassmorphism ni néon.
- Typo géométrique façon Futura : **Jost** (OFL), licence copiée dans le hmod.
- Musique : morceau **original** (aucune mélodie, motif ni sample Konami), gothique énergique, mode mineur, clavecin + orgue façon 16 bits, basse qui avance, boucle ≈ 60 s sans couture. Format : WAV PCM 16 bits, 44 100 Hz, stéréo (comme `bgm_home.wav` d'origine). L'utilisateur l'écoute et la valide avant le hmod.
- `clover-ui` : on remplace uniquement des ressources (images, polices, sons), jamais les scripts Lua compilés, la disposition ni les animations. Console EUR → `/usr/share/ui/snes-eur/resources/`. Ne pas toucher aux `strings.lng` montés en tmpfs par hakchi.
- La console a déjà `font_remount` (police `title` personnalisée « Yu Gothic UI » dans `/var/lib/hakchi/rootfs/usr/share/fonts/title.fnt`) : le hmod ne doit pas la détruire ; la désinstallation la rend.
- RetroArch : sauvegarder `/etc/libretro/retroarch.cfg` avant toute écriture ; ne pas casser les overrides `config/PCSX-ReARMed/PCSX-ReARMed.cfg` et `config/4DO/4DO.cfg`. `config_save_on_exit = "true"`.
- **Aucune écriture sur la console sans accord explicite de l'utilisateur dans le chat et sans sauvegarde préalable** (`P:\Backups\SNESMini_2026-11-10\` existe déjà ; refaire un tar de `/var/lib/hakchi` et `/etc/libretro` juste avant). Pas de flash. Console SSH `root@169.254.13.37` (lecture seule autorisée).
- Référence locale des ressources d'origine : `P:\HakchiSNESUSA\ui_ref\` (copie lecture seule de `/usr/share/ui/snes-eur`). Ne jamais committer ces fichiers Nintendo : `theme/` ne contient que du code, des tests sur fichiers générés, et des fixtures minuscules fabriquées.
- Sorties lourdes (WAV, atlas, hmod) dans `P:\HakchiSNESUSA\theme_out\`, jamais dans le dépôt.
- Ne jamais tuer un processus par nom d'image ; toujours par PID.
- Tests : `python -m pytest theme/tests -q` (doit rester vert à chaque commit).

## Review Focus

1. Désinstallation : après `uninstall`, chaque fichier lié par le hmod revient à l'original et la `title.fnt` de l'utilisateur est toujours liée → test du script de désinstallation (Task 6).
2. Glyphes manquants : les chaînes FR/EN/DE/ES/IT/NL/PT du menu (accents, `ß`, `œ`, `«»`, `€`) doivent toutes exister dans les polices générées → test de couverture contre le jeu de caractères des polices d'origine (Task 2).
3. Atlas : un sprite repeint qui déborde de son cadre ou change de taille casse l'affichage → test « les cadres du JSON sont inchangés et rien n'est écrit hors des cadres repeints » (Task 3).
4. Couture de la boucle musicale : clic audible au bouclage → test de continuité au point de boucle (Task 5).
5. Console sans clé USB / sans `font_remount` : le hmod doit quand même s'appliquer (chemins `installpath`) et ne jamais bloquer le démarrage → `sh -n` + test que chaque bind est conditionné à l'existence des deux fichiers (Task 6).

### Task 1: Codec des polices `.font` / `.fnt`

Format observé : octet `01`, taille LE 24 bits du bloc BMFont, `00`, taille LE 24 bits du bloc PNG, `00`, puis le BMFont **binaire v3** (`BMF\x03`, blocs 1–4/5 AngelCode) et la page PNG.

**Files:**
- Create: `theme/b1/clover_font.py`, `theme/tests/test_clover_font.py`, `theme/tests/fixtures/` (petite police fabriquée par le test, pas de fichier Nintendo)

**Interfaces:**
- Produces: `parse(data: bytes) -> CloverFont` (`info`, `common`, `pages: list[str]`, `chars: dict[int, Glyph]`, `kernings`, `png: bytes`) ; `build(font: CloverFont) -> bytes`.

- [ ] **Step 1: tests** : `test_roundtrip_synthetic` (une police construite en mémoire → `build` → `parse` → égale) ; `test_roundtrip_reference` marqué `@pytest.mark.skipif` si `P:\HakchiSNESUSA\ui_ref` absent : pour `l.font`, `m.font`, `s.font`, `copyright.fnt`, `title.font`, `build(parse(x)) == x` octet pour octet.

- [ ] **Step 3: Commit** `feat(theme): codec des polices clover-ui`.
